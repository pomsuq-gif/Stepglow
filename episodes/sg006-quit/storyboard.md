# SG006 — Who quits first? (Which one carries you?): раскадровка

Идея — из подсказки YouTube Studio («Who quits first when the test becomes impossible», продолжение лучшего по удержанию
SG005 «Who reaches the top?»). Сценарий доработан: испытание = **бесконечная каменная лестница на горном хребте**
(ступени — главный образ канала), у каждого на спине тяжёлый камень; ночь → буря → вершина.
Финал-перевёртыш: Obsession первым на вершине, но **не может остановиться** и уходит дальше по лестнице,
которая продолжается к пику ещё выше, с камнем на спине; Discipline ставит свой камень на вершине, и тот
становится маяком. Вопрос зрителю: «Which one carries you?» (двойной смысл: carry — нести камень / вести тебя).

Стиль: **Inner Light, чистый** (`sg002-start-small/look.ts → SG`). Музыка — трек SG002 (`studio/public/sg006/music.m4a`,
в git не кладём; копия `studio/public/sg002/music.m4a`): короткое вступление → бас на 5,54 с → **тихая пауза
23,6–25,6 с** → мощный возврат на 25,82 с — ровно под драматургию «выбывают по одному → тишина у вершины → маяк».
Трек SG005 был бы ещё уместнее по смыслу, но его нет в репозитории (берётся из эталона локально), а скачать с YouTube
из облачной среды нельзя. Сетка (`grid.ts`): бит 0,6338 с, `beat(0)` = 5,54 с (перепроверено по 66 онсетам, ошибка 26 мс).

Композиция `SG006-Full` · 1080×1920 · 60 к/с · 33,5 с. Код: `studio/src/episodes/sg006-quit/`.

**Новое в наборе:**
- `plan.ts → walk(n)` — подъём 3D-стикмена (`rig3`) по ступеням: `n` = число шагов; ступни **стоят на ступенях**
  (одна нога — одна ступень, через одну), мах стопы по дуге над кромкой, таз едет по рампе через центры ступеней,
  наклон/присед/раскачка — параметры. `carry()` — камень на верхней части спины, кисти через плечи на камне;
  `backStone()` — центр камня от позы. `simStone()` — камень, сброшенный со спины: физика с отскоками по ступеням,
  скатывается вниз и останавливается на площадке.
- `World.tsx`: лестница — один меш со своим шейдером (кромки ступеней ловят луну, снежная пыль, отсвет огоньков в груди,
  **пройденные ступени светятся цветом героя и гаснут позади**), фонарики вдоль лестницы до самых облаков,
  хребты-силуэты по кругу со снегом на гребнях, гигантский пик, толпа с телефонами (вспышки), прожектор на Ego,
  буря (облака, косой снег, молнии на сильных долях), маяк (золотой камень, луч в небо, кольца, искры).
- `scripts/sg006-check.ts` — проверка поз: части тела внутри ступеней + скачки суставов.
